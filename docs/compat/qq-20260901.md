# QQ Mail live smoke record — 2026-09-01

Status: owner-operated, redacted Windows smoke test. This is compatibility evidence for the tested account and date, not a Tencent guarantee and not the complete M8 spike suite.

## Confirmed

- `auth login` verified the authorization code before saving it to Windows Credential Manager.
- `envelope list --folder INBOX --unread --json` returned real unread envelopes.
- `message show <id> --json` returned the selected message body with `ok=true`, `truncated=false`, and the primary `go-message` parser.
- After `message show`, the same opaque message ID remained in a second `--unread` query.
- The QQ Mail web inbox still showed the target with its yellow unread icon and bold row after refresh. This confirms read-only PEEK behavior for this observation.
- Windows PowerShell 5.1 needed `[Console]::OutputEncoding` and `$OutputEncoding` set to UTF-8 before piping Chinese JSON into `ConvertFrom-Json`.

## Observed follow-up

- A QQ system message exposed an RFC 2047 encoded-word as the parsed sender display name. A tolerant second decoding pass and regression coverage were added after this observation.
